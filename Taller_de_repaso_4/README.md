Taller de Reforzamiento: Subconsultas en el Esquema HR de Oracle SQL

Este repositorio contiene las soluciones para el taller de reforzamiento sobre subconsultas en el esquema HR de Oracle SQL. Se incluyen ejercicios de subconsultas utilizadas como campos, en el FROM y como condicionales, además del uso de la función ROW_NUMBER().

📌 Estructura de los Ejercicios

🔹 Ejercicios 1-3: Subconsultas como campos en el SELECT

Empleados con salario mayor al salario promedio.

Empleados con comisión mayor que el promedio.

Empleados con más antigüedad que el promedio.

🔹 Ejercicios 4-6: Subconsultas en el FROM

Empleados del departamento con más empleados.

Empleados con un cargo superior al del empleado con el mayor salario.

Empleados del departamento con el mayor salario promedio.

🔹 Ejercicios 7-9: Subconsultas como condicional

Empleados que ganan más que el promedio si el salario es mayor a 100,000.

Empleados con más hijos que el promedio, si tienen más de 2 hijos.

Empleados con más edad que el promedio, si tienen más de 50 años.

🔹 Ejercicios 10-12: Uso de ROW_NUMBER()

Empleados ordenados por salario de mayor a menor con número de fila.

Empleados ordenados por departamento con número de fila.

Empleados ordenados por fecha de contratación con número de fila.

⚙️ Requisitos

Acceso a una base de datos Oracle SQL con el esquema HR.

Un entorno de consulta SQL como Oracle Live SQL, SQL Developer o cualquier otro compatible.

🚀 Ejecución de las Consultas

Conectar a la base de datos Oracle.

Ejecutar cada consulta en el orden indicado.

Verificar los resultados y compararlos con las expectativas del taller.
