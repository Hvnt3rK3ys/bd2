# Taller de Consultas SQL

## Descripción
Este taller contiene una serie de consultas SQL diseñadas para practicar el uso de diferentes tipos de **JOIN** en bases de datos relacionales. Se incluyen ejemplos de `JOIN`, `LEFT JOIN`, `RIGHT JOIN`, creación de tablas (`CREATE TABLE`) e inserción de datos (`INSERT INTO`).

## Contenido

### 1. Uso de JOIN
Se incluyen consultas que calculan estadísticas salariales para empleados en diferentes departamentos y posiciones dentro de la empresa.

### 2. Uso de LEFT JOIN
Consultas para identificar departamentos sin empleados, empleados sin asignación de departamento y estadísticas salariales de estos empleados.

### 3. Uso de RIGHT JOIN
Consultas para identificar departamentos sin gerentes, empleados que no son gerentes y estadísticas salariales asociadas.

### 4. Creación de Tablas (`CREATE TABLE`)
Creación de tablas basadas en consultas, como `employees_info` y `departments_info`.

### 5. Inserción de Datos (`INSERT INTO`)
Ejemplos de inserción de datos, incluyendo inserción de nuevos empleados y duplicación de datos en tablas de respaldo.

## Estructura del Archivo SQL
Las consultas están organizadas en el archivo `queries.sql` con los siguientes bloques:

- **JOIN:** Consultas relacionadas con combinaciones entre empleados y departamentos.
- **LEFT JOIN:** Consultas que identifican datos faltantes en la relación de empleados y departamentos.
- **RIGHT JOIN:** Consultas similares a LEFT JOIN pero enfocadas en gerentes.
- **CREACIÓN DE TABLAS:** Definición de nuevas tablas a partir de consultas.
- **INSERCIÓN DE DATOS:** Inserción de nuevos registros en la base de datos.

## Uso
Para ejecutar las consultas, carga el archivo `queries.sql` en tu gestor de base de datos y ejecútalas en orden. Puedes modificar los valores según tu necesidad.
